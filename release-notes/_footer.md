### ⬇️ Download
Grab the zip for your OS below, extract and run LabelForge:
- Windows → `LabelForge-win-x64.zip`
- Linux → `LabelForge-linux-x64.zip`
- macOS → `LabelForge-mac-arm64.zip`
- Arch Linux → `yay -S labelforge-bin` (community package, thanks [@gyfooya](https://github.com/gyfooya))

⚠️ Only ZPL is tested on real hardware. TSPL/EPL/CPCL/EZPL are experimental.
The app is not code‑signed, so Windows SmartScreen may warn on first run.
