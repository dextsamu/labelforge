## LabelForge v1.19.0 — Smart fields & true-size codes

### ✨ What's new
- 📅 **Automatic fields** — no typing needed, filled at print time:
  - `{{date}}` today · `{{date+30}}` in 30 days (also `+6m`, `+1y`, negative offsets) — perfect for expiry dates
  - `{{date:YYYY-MM-DD}}` custom format (`YYYY YY MM DD HH mm ss`) · `{{time}}` · `{{now}}`
  - `{{counter}}` / `{{counter:4}}` → `0001, 0002…` one number per printed label, copies included
  - **Counter from** field in the print view: numbering continues automatically from the last print, per template (also `counterStart` in the HTTP API and `--counter-start` in the CLI)
- 📝 **Multi‑line text** — new *Max lines* property: long text wraps inside the box (or the label width). ZPL uses the printer's native `^FB` block.
- 🔳 **True-size QR & DataMatrix** — the preview now draws them at the real printed size (it used a rough estimate before), selection/resize use the real size, and both can be **aligned** left/center/right like text and barcodes.
- 🤖 **Automatic release notes** — GitHub releases are now written from `release-notes/` or the CHANGELOG at build time.

### 🔧 Details
- QR preview now uses the same error-correction level as the printer (Q), so module count matches the print.
- Automatic fields are not shown as inputs; your own data still wins (e.g. a CSV column named `date`).
- Existing templates without these features print exactly as before.
